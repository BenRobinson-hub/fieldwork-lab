01 / QUESTION

Can multi-replica routing split a stateful MCP session across Pods?

02 / METHOD / SOURCE

A publicly reported bounded independent reproduction on Higress 2.2.4 with two Streamable HTTP replicas; the comment compares hashing and affinity conditions.

Read the exact comment on GitHub ↗

03 / REPORTED RESULT

The author reports 404 / unknown-session outcomes when requests reach a replica that did not create the session. ClientIP affinity did not eliminate the behavior in 10 sampled flows; source-address hashing provided bounded continuity in 10/10 flows.

04 / WHAT IT CAN SUPPORT

Within the reported test scope

The published account supports a traceable and technically specific report of the observed cross-replica mechanism under its declared setup. The controls and sample results are available to read and scrutinize in the public comment.

05 / WHAT IT CANNOT PROVE

Do not infer beyond the run

It does not establish the original Kubernetes 1.30.3 / Higress 2.1.11 environment was recreated, that source-IP hashing is a universally correct repair, or that current upstream has accepted or fixed the behavior.

06 / BOUNDARY & TRACEABILITY

Original fixture archives are not published on this site. The report is author-supplied public evidence; source is dated and must be rechecked before making current-branch claims.
